# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## Managed MongoDB Database Tools

Opening **Dump / Restore** makes Compass+ check MongoDB's official Database
Tools release catalog. The app downloads the latest archive for the current
operating system and CPU architecture, verifies its SHA-256 checksum, and
installs `mongodump` and `mongorestore` under the platform-specific application
data directory. A valid installed version remains available when an update
check cannot reach MongoDB.

MongoDB Server, Homebrew, and MongoDB Database Tools do not need to be
installed system-wide for dump and restore operations.
